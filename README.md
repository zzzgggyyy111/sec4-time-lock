时间锁的释放时间写成了本地时间，服务器换个时区之后，本该锁半年的文件提前解开了：释放时间必须统一使用带显式时区的时间表示并归一到同一时间基准；未到释放时间不得解密；释放时间只能延后不能提前；时间锁必须绑定内容摘要；时区与格式必须校验；批量处理时每个文件独立判定。不变量是任何未到期的文件都解不开，且释放时间不会被提前。

## 契约

- 释放时间必须使用统一时区。
- 未到释放时间不得解密。
- 释放时间只能延后不能提前。
- 时间锁必须绑定内容摘要。
- 时区与格式必须校验。
- 批量处理各文件独立。

## 不变量

- 任何未到期的文件都解不开。
- 释放时间不会被提前。

## 锁头

锁头是单行文本，首字段为 TLOCK1，后续字段以分号分隔。release 字段保存带显式时区的 ISO 8601 时间，digest 字段保存 sha256 与 64 位十六进制摘要。解析后的释放时间以纪元秒表示，摘要统一为小写。
